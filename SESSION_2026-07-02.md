## Known issue — publications stale (OpenAlex-side, not ours)
- **2025 publications did NOT update** — OpenAlex returned **HTTP 503 on all 30 domains**, twice (during the review and a dedicated backfill retry).
- **Root cause confirmed:** OpenAlex's `default.search` (full-text) subsystem is degraded. The basic filter API (`publication_year:...`) returns 200; the `default.search:<kw>,authorships.countries:<ISO>` queries the module needs return 503. Verified by curl side-by-side.
- **No data lost:** resilient design kept the prior **2026-06-17 vintage** (never zeroed).
- **Retry (idempotent):**
  ```
  cd tech_sci_jobs && PYTHONPATH=. python3 -c "from research_sources import publications; print(publications.run(year=2025))"
  ```
  then re-snapshot, commit `data/research`, push. **Health gate:** a `default.search:` query must return 200 — the plain `publication_year` filter returning 200 is NOT sufficient (that stays up during search outages).
- The **Mon 2026-07-06 weekly cron** will attempt this automatically.
